# בקאנד טופס המועמדות — בלי גוגל

**החלטה (17.08):** הלקוח ביקש לא להכניס קוד לגוגל. הגרסה של Apps Script הוסרה
(ניתן לשחזר מהיסטוריית git, commit `8099749`), והוחלפה ב-**FormSubmit**.

## למה FormSubmit

| דרישה | איך זה נענה |
|---|---|
| בלי קוד בגוגל | אין. רק POST ל-HTTPS |
| בלי חשבון ובלי הרשמה | אין רישום, אין API key |
| HTTPS | חובה — הדף מוגש מ-GitHub Pages ב-HTTPS |
| בלי סודות בקוד | אין. אין מה לגנוב — ה-endpoint יודע לעשות דבר אחד: לשלוח מייל לכתובות הקבועות |
| מגיע לשתי הכתובות | הראשית + `_cc` |

אומת בפועל שה-endpoint מחזיר `Access-Control-Allow-Origin: *`, כלומר הדף יכול
לקרוא את התשובה ולהציג הצלחה/כשל אמיתיים ולא לנחש.

## איך זה מוגדר

ב-`v11.html`, בתוך ה-`<script>`:

```js
var SUBMIT_ENDPOINT = "https://formsubmit.co/ajax/info@yarenunissim.com";
var NOTIFY_CC       = "mak720431@gmail.com";
```

הפנייה נשלחת עם **תוויות בעברית**, כך שהמייל שהצוות מקבל נראה כמו טבלה קריאה
(`_template: table`) ולא כמו שמות שדות באנגלית.

## ⚠️ הפעלה ראשונה — חובה פעם אחת

FormSubmit דורש אישור חד-פעמי של כתובת היעד:

1. הפנייה הראשונה שנשלחת מהדף מפעילה מייל **"Confirm your email"** שנשלח ל-`info@yarenunissim.com`.
2. מישהו עם גישה לתיבה הזאת צריך **ללחוץ על הקישור באותו מייל**.
3. מאותו רגע כל פנייה מגיעה ישירות, בלי שום שלב נוסף.

**עד שזה נעשה — פניות לא יגיעו.** זה השלב היחיד שנותר.

## הערת פרטיות שכדאי לטפל בה

הכתובות מופיעות ב-**קוד המקור הפומבי** של הדף, ולכן חשופות לקצירת ספאם.
`info@yarenunissim.com` ממילא פומבית (היא מופיעה בדור הקודם של הדפים), אבל
`mak720431@gmail.com` נחשפת כאן בפעם הראשונה.

**חיזוק מומלץ (דקה):** אחרי האישור, FormSubmit מספק **כתובת אליאס** אקראית
(`https://formsubmit.co/ajax/xxxxxxxxxxxx`). מחליפים בה את ה-endpoint ואז אף
כתובת מייל אמיתית לא מופיעה בקוד. תנו לי את האליאס ואחליף בכל 8 הדפים.

## מה קרה לגיליון

הגיליון "מועמדויות — ישיבת יראנו ניסים" שנוצר ושותף **נשאר קיים אבל אינו מתמלא
יותר**, כי מה שכתב אליו היה ה-Apps Script שהוסר. FormSubmit שולח מייל בלבד.

אם בהמשך תרצו טבלה משותפת שמתמלאת אוטומטית **בלי גוגל**, שתי דרכים בלי קוד בגוגל:
- **Airtable / Notion** — יש להם endpoint לקבלת טפסים, אבל דורשים חשבון.
- **הרצה על ה-VPS שלנו** — אפשרי, אבל דורש דומיין ותעודת HTTPS. כרגע ה-VPS מגיש
  HTTP בלבד, ודף HTTPS לא יכול לשלוח אליו (mixed content). זה יידרש נגיעה
  ב-`nanox-caddy` — ולכן לא נעשה בלי אישור מפורש.

בינתיים: **המייל הוא מקור האמת**, ושתי הכתובות מקבלות כל פנייה.
