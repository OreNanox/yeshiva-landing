## הפתרון: FormSubmit + כתובת אליאס

| דרישה | איך זה נענה |
|---|---|
| בלי קוד בגוגל | אין. רק POST ל-HTTPS |
| בלי חשבון / API key | אין רישום בכלל |
| HTTPS | חובה — הדף מוגש מ-Pages ב-HTTPS |
| **בלי כתובות מייל בקוד** | ה-endpoint הוא **אליאס אטום** של FormSubmit |
| בלי סודות | האליאס אינו סוד — הוא יודע לעשות דבר אחד: לשלוח מייל ליעד קבוע |

אומת בפועל: ה-endpoint מחזיר `Access-Control-Allow-Origin: *`, כך שהדף קורא את
התשובה ומציג הצלחה/כשל **אמיתיים** ולא מנחש.

## מצב נוכחי

```js
var SUBMIT_ENDPOINT = "";   /* ← להזין כאן את האליאס */
```

**ריק בכוונה.** עד שיוזן אליאס, הטופס מציג הודעת שגיאה כשרה ולא מתחזה להצלחה,
ואף כתובת מייל לא נחשפת בקוד המקור הפומבי.

## הערות תחזוקה

- FormSubmit דורש כותרות `Origin`/`Referer` — מדפדפן אמיתי זה אוטומטי. שליחה
  מ-`curl` בלי `-H "Origin: ..."` תיענה בשגיאה "open this page through a web server".
- התגובה מחזירה `success` בתור **מחרוזת** (`"true"` / `"false"`) ולא בוליאני.
  הקוד מטפל בשניהם — **אל תשנו לבדיקת `=== true`** או כל שליחה אמיתית תיראה ככשל.
- הגיליון שנוצר ב-17.08 **אינו מתמלא יותר** (מה שכתב אליו היה ה-Apps Script שהוסר).
  המייל הוא מקור האמת. לטבלה משותפת אוטומטית בלי גוגל צריך שירות עם חשבון
  (Airtable/Notion) או HTTPS על ה-VPS — שדורש נגיעה ב-`nanox-caddy`, ולכן לא בוצע.
